# 失真对照：需求到研发手里还剩多少、对不对

> 全部为模拟数据：占位种子 + `data/sim/cards.jsonl` 前 60 张程序生成的需求卡，模拟客户用模板模式，抽取、觉、转译全是规则实现。
> 复现：`uv run python scripts/run_distortion.py --cards data/sim/cards.jsonl --n 60`（约 3 秒；同一种子重跑结果逐字节一致）。
> 数字见 `metrics.json`、`table.csv`，图 `distortion.png`。觉调用 202 次，**大模型调用 0 次**。

## 三组做法

同一张卡、同一个模拟客户随机种子（三组听到的开场白相同）：

| 组 | 做法 | 研发拿到什么 |
|---|---|---|
| G1 业务员转述 | 不用觉的提示，业务员按习惯只问面料，再凭印象写给研发 | 按**假设的转述噪声**加工后的现象和槽位，没有原话、没有依据 |
| G2 一次性翻译 | 不追问，只有客户开场白；用全部转化对照（L2、L3 混用、不按现象过滤）匹配一次 | 开场白抽到的槽位 + 直接产出的化学语言条目 |
| G3 化言 | 按觉的提示追问（最多 8 轮）→ L2 产品需求 → L3 化学语言需求单 → 对 L3 草稿**回问**（觉发现缺一个会改变转译的信息，问客户），回填后重新起草 L3 | L3 需求单（每条带客户原话与所引转化知识） |

另列「G3 化言（不含回问）」，即回问之前的 L3 草稿，用来看回问本身的作用。

## 结果（60 张卡）

| 指标 | G1 业务员转述 | G2 一次性翻译 | G3 化言（不含回问） | **G3 化言** |
|---|---|---|---|---|
| 关键信息完整率（现象 + 必问槽位，值正确） | 51.1% | 40.1% | 85.2% | **89.6%** |
| 槽位错误率 | 6.6% | 0.0% | 0.0% | 0.0% |
| 错译率（所引转化知识不属于该现象的条目） | —（不引用知识） | 10.8% | 0.0% | 0.0% |
| 平均追问次数 | 1.00 | 0 | 1.37 | 1.37 |
| 平均回问次数 / 其中事后有用 | — | — | — | 0.90 / 40.7% |
| 可回查率（带客户原话的条目） | 0% | 100%（只有开场白一句） | 100% | 100% |
| **研发需退回比例**（现象不明，或任一必问槽位缺失 / 错误） | 96.7% | 100% | 43.3% | **30.0%** |

300 张卡重跑（`--n 300`）方向与幅度一致：完整率 46.1% / 41.1% / 82.2% / 85.9%，退回比例 97.3% / 99.0% / 51.0% / 39.7%。

- **化言把研发需退回的比例从约 97% 降到 30%**：差别主要来自觉的追问（完整率 51% → 85%）；回问再把完整率提高 4.4 个百分点、退回比例降低 13 个百分点。
- 一次性翻译不追问，开场白里通常只有现象，必问槽位几乎全缺；不按现象过滤的转化对照会错配（10.8% 的条目引用了别的现象的知识）。它的「可回查」只能回到开场白一句。
- G3 仍有 30% 的卡被退回，**全部是必问槽位缺失**（现象 60/60 识别正确）：觉追问的依据是「问了能不能改变 L1 的候选产品」，像「起皱印 × 面料」「白度不够 × 工艺」这类必问但不影响候选的槽位，觉不问；回问只补「会改变 L3 转译」的槽位。这是觉目标的真实边界，没有为本对照调阈值。

## 必须说明的三点

1. **G1 的噪声来自假设参数**（`config/eval/distortion.yaml`）：现象被说成笼统的「染色有问题」0.3、每个已知槽位漏记 0.2、记错 0.1，业务员按习惯只问面料。依据是一线业务需求交流中的共识「客户和业务员不懂化学，只会描述宏观现象；业务员再加工转述，需求就变形了」，比例本身没有实测。企业数据到位后用真实转述样本替换。
2. **单卡对照是按固定规则选出的例子**（`docs/reports/single_card/`，与本报告同一次运行）：演示第一幕看的是那一张卡，证据是本页的统计。
3. **G3 的槽位错误率偏乐观**：模板客户与规则抽取共用种子中的口语说法表，客户说的话一定能被准确抽到，所以 G2、G3 的槽位错误率都是 0。真实对话中抽取会出错，这一项要用大模型扮演客户 + 大模型抽取再测。

## 局限
- 需求卡、客户都是模拟的；客户被问到才说、不会主动纠正。
- G3 只取觉的第一条提示追问，一次问一个槽位；回问最多 2 个槽位，觉为规则原型（阈值同 `config/app.yaml`）。
- 未做可选的大模型附加列（G2 换真大模型一次性翻译、G3 由助手在规则骨架上修改）。
