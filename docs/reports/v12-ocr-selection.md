## 两条路

| | 本地 RapidOCR（rapidocr_onnxruntime 1.4.4，CPU） | 网关视觉模型（`deepseek-v4.1-flash`，`caller=ingest:extract`） |
|---|---|---|
| 正文 | 好；与视觉模型的汉字序列相似度 0.97–1.00（9/11 页） | 好；同左 |
| 标题层级 | 无 | 有（Markdown 标题、条款号） |
| 表格 | 一格一行，行列全丢；旋转表基本不可读 | Markdown 表，表头单位齐全；旋转长表 6 行中 5 行逐格正确，1 个多值合并格错位 |
| 公式 | 上下标、分式打散，常有错字 | LaTeX，主干正确；个别上下标（α 的下标、一处平方）有出入 |
| 双栏图题 | 两栏逐行交错，图题被拆碎 | 按图分开，图题与 GC 条件各归其图 |
| 印章水印 | 不受影响 | 不受影响 |
| 速度 / 成本 | 约 4.5 s/页，1612 页约 2 小时，免费，离线 | 约 10 s/页（一页因重试 135 s），单页约 2200 输入 + 450 输出 token；全量约 360 万输入、75 万输出 token |
| 运行方式 | 新增 onnxruntime、opencv 依赖 | 零新依赖，C1 图片输入与网关计量、缓存现成 |

## 结论

**主解析器选网关视觉模型（`deepseek-v4.1-flash`，经现有网关与 `data/pilot/models.yaml`）。** 正文两者一样，差别全在表格、公式、图题和标题层级，而这些正是教材知识所在；本地 OCR 产出的碎行既难检索也难阅读。

要如实标注的：
- 转写是模型读稿，不是原生文字：表格多值合并格、公式上下标可能有错；读取结果须标明来源于模型转写，引用前对照 `read_source_image` 原图；
- 1612 页考点一教材与国标（登记为 L3 内部，本身为出版物）会发往试用接口；
- 失败的页保持待补读，不硬填。
