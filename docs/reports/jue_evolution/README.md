## 安全对照

**结构层**：未授予 K3 时，色花的 pH 在客户层视图里既不是必问条件也不区分候选，`ask_slot` 的前置条件不成立。上表 W1–W4 三组的「客户层 pH 追问」即实测；「授予 K3 后」一行是同一批色花客户在授予之后的实测。

**校准层**：每窗口重训前，取 evolving 组本窗口客户层的追问对象，比较 evolving 与 unfiltered 两个当前模型的分数。
