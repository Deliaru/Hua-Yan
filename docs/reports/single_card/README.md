# 单卡对照

> 全部为模拟数据。由 `scripts/make_single_card.py` 生成，与 `docs/reports/distortion/` 是**同一次运行**（60 张卡）；
> 觉：`jue_proto`，追问阈值 0.5、回问阈值 0.5；大模型调用 0 次。展示数据见 `metrics.json`。

## 选卡（规则写死，不挑）

现象为 color_unlevel、G2 一次性翻译被研发退回、G3 化言不被退回的卡中 id 最小的一张；没有则取第一张同现象卡。60 张卡中同现象 7 张，**满足条件 7 张**，选中 `card:16`。

## 这张卡

- 客户知道的必问信息：fiber=棉、equipment=气流染色机
- **一次性翻译**：只听开场白「客户投诉说发花，有什么办法吗？」，研发退回（缺：面料成分、染色设备）。
- **化言**：觉提示追问 fiber，回问 equipment、bath_ph，研发不退回。

## 必须说明

1. **单卡是按固定规则选出的例子**，不代表每张卡都这样；证据是上面的统计。
2. G1 的转述噪声是假设参数（`config/eval/distortion.yaml`），见 `docs/reports/distortion/README.md`。
3. 模板客户与规则抽取共用种子里的口语说法表，G3 的槽位错误率偏乐观。
4. 规则打分的追问、回问在界面上标「规则」，不显示为概率。
