# 赛事要求摘要

> 来源：赛事官网 http://asserts.dsdigital.team/static/transfar/transfar-dsgroup-ai-architect-hackathon.html （2026-10-10 读取）。以官网最新内容为准。

## 赛道：AI＋功能化学

**业务背景**：传化功能化学深耕纺织印染助剂，提供化学产品、应用技术和专业解决方案。客户在面料、工艺、设备、目标性能上差异大，需求高度个性化，专业服务依赖专家经验。业务环节：研发、生产、供应链、销售与服务。

**自主选题**：选题不限于推荐场景，鼓励自主识别痛点。

**重点推荐场景「AI 化学家」（销售与服务）**：通过专业知识检索辅助生成客户解决方案。探索方向：
- 专业需求理解：多轮问答理解客户需求，识别面料类型、目标性能、关键工艺条件；
- 专业知识检索与融合：检索内部产品、配方、工艺、实验知识，按需融合外部专利文献，回答准确、可追溯；
- 解决方案辅助生成：推荐适用产品、应用工艺及后续实验验证方向。

**官方列出的痛点**：客户需求理解困难（描述不专业、难以标准化）；专业知识分散、难以复用；内外部知识融合不足（外部知识容易覆盖内部知识）；复杂知识理解能力有限（偏检索拼接，缺跨文档推理）；方案生成依赖专家经验。

**数据示例（终赛提供）**：产品与工艺知识、实验与应用案例、外部专业知识、业务问答样例。

**其他三个方向**：纺织助剂配方优化、生产设备清洗切换优化、关键原材料缺料预警。

## 提交要求

- 截止前通过指定渠道提交**一个 GitHub 私有仓库链接**，邀请官方账号 `DsChHack` 为协作者。
- 仓库包含代码、README、运行说明。README 需介绍团队信息（可附简历）、业务场景、核心方案、应用价值。
- 技术实现：说明关键算法与模型、技术架构、数据来源、外部依赖、运行方式、测试结果、当前限制。
- Demo 展示**可选**：在线应用、HTML、视频或交互示例；大附件可用网盘，链接须在评审期有效。
- 合规：原创或拥有合法使用权；**明确标注开源组件、模拟数据及人工操作环节**；**参赛后提交作品的知识产权归主办方所有**。

## 评审标准（五项各 20%）

1. **技术可行性与实现可信度**：技术路线合理；以原型、代码、测试记录支撑主张；材料与实现一致；数据、算力、外部服务等依赖合理。
2. **技术创新与效率提升**：算法、模型、架构、工程上的创新；计算效率、数据利用率、响应速度、资源成本、输出质量的改善；用测试数据或与现有做法的对比提供可核查支撑。
3. **业务价值与场景契合度**：明确目标用户、痛点、使用流程；技术输出如何支持决策或执行；区分已验证效果与预期收益。
4. **工程化潜力与规模扩展能力**：数据量、任务量、用户数、复杂度增长时的性能、成本、稳定性；资源需求、瓶颈、扩展思路。
5. **企业落地可行性与应用潜力**：数据与资源条件、业务流程与系统对接、部署维护成本、数据安全约束；实施路径、关键障碍及解决思路。

## 评审与后续

- **初赛**：评委结合代码、README 和支撑材料评审，必要时联系团队核实技术实现与测试结果。
- **方案打磨**：晋级团队将获得进一步细化的业务需求与真实业务数据。
- **决赛**：现场 PPT 路演与答辩，可辅以 Demo。
- 晋级后提供的真实数据按赛事方规则使用，未经书面许可不得外传或用于赛事以外的用途。
- 作品不要求完整商业化，但应有可验证的技术实现基础，并说明应用价值、现阶段限制和落地路径。
