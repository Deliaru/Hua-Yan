# 产品经理试用说明

**入口**：选身份时点「产品经理」下面你的名字，进入「产品经理」工作面。

逐单把客户需求转成产品需求的工作，由产品经理 Agent 在后台完成，你不用每单转述。你只处理三类需要产品判断的事，都在左栏：

| 左栏分组 | 什么时候出现 | 你要判断什么 |
|---|---|---|
| 适用范围待定 | 研发判「已有产品适用」，产品适用的条件要扩大 | 这个产品的适用范围要不要按研发的判断扩大。扩大后，同样条件的客户自助就能直接得到推荐 |
| 产品机会 | 同一类需求反复转研发，又没有产品可用 | 值不值得把几个客户的需求合并成一个研发课题 |
| 待纠偏 | 研发把产品经理 Agent 写的需求退回 | 改正有问题的条目，再交回研发 |

## 按钮是什么意思

| 按钮 | 作用 |
|---|---|
| 扩展适用范围 | 签字同意按研发的判断扩大适用范围，卡片上列出了适用条件和研发写的限制 |
| 合并为一个课题 | 把几个客户的同类需求合成一张研发需求单 |
| 保存 | 保存你对某条产品需求的修改 |
| 修改完成，交研发 | 纠偏改好，交给研发重新接单 |
| 沉淀为我的知识 | 把你改出来的「客户说法 → 产品需求说法」存成你名下的知识，以后 Agent 转译会引用，并给你记贡献 |
| 现在不需要 | 这件事现在不处理 |

右侧「你的判断产生了什么」统计 Agent 替你省下的转述，以及你的判断之后自动解决了多少需求。

「觉视图」可以按需求单看觉在这条线上每一次提出了什么、交给了谁、谁签了字。
