# 客户试用说明

由项目方陪同人员或业务员扮演客户时看这一页。

## 1. 打开收件箱

选身份时点「客户」下面的印染厂，进入「客户」工作面。左栏「我的需求」是你提过的每件事，旁边写着现在的状态：等你补充情况、已有推荐、已转研发、已记录。

## 2. 处理第一件事

- 「等你补充情况」：化言在问你问题，照实回答就行，可以用自己的话，不用懂产品名；
- 没有需求时，在左栏点「＋」→「用自己的话说」开一个新需求，像跟业务员打电话一样说现象，比如「深一块浅一块」；
- 拿到推荐卡后，可以直接问用法，也可以说要报价，化言会交给你的业务员；
- 「已转研发」说明现有产品解决不了，研发会带着你说过的原话处理；研发要回问时，问题会出现在这里。

中间的「我的需求进度」写着这件事走到哪一步、接下来会去哪。右上角「演示说明」打开后，可以看到化言在背后做了什么，以及同一件事按原来的流程要经过几个人（推算）。

**注意**：试用里标「模拟」的内容是项目方补的，不当作真实判断；拿不准的请问现场陪同人员。
