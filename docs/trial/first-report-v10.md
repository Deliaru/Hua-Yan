## 共享实例与运行方式

本次启动与实际核验见[共享服务核验页](../../data/knowledge_v10/checks/shared-online-20261102/review.html)。当前已有服务时直接访问，先选实际身份；不要重复运行下方启动命令。核验时五候选仍candidate、cap:1仍proposed，无客户会话或需求单。研发助手只读委托及后台PM准备是开发者启动检查记录，不算本人专业操作。启动保存只将知识库version从7增至8，专业内容及状态保持。

先在项目根目录生成当前交接：

```powershell
uv run --locked --no-sync python scripts/package_v10_handoff.py
```

脚本只读取已有证据并生成本地索引、输入指纹及在线配置，不启动服务、不调用模型、不改业务状态。默认输出 `data/knowledge_v10/validation/finals-handoff/`。附本次服务核验快照时，加`--service-check data/knowledge_v10/checks/shared-online-20261102/summary.json`；快照不保证之后服务持续在线。

服务未运行时，项目方在确认8769端口没有其他化言进程后，启动同一个共享运行：

```powershell
$env:HUAYAN_PORT="8769"
uv run --env-file .env --locked --no-sync python -m huayan.ui.server --trial human-review-ready --config data/knowledge_v10/validation/finals-handoff/app.human-online.yaml
```

该配置使用config/models.agent.yaml指定的业务模型、Cloudflare clef-flash、LLM抽取和object对话；读取模型另由config/models.yaml指定；环境变量从本地 `.env` 注入。只做人工审阅时，可改用原 `data/knowledge_v10/validation/human-ready-20261101/app.yaml`，此模式是mock/规则，不能记为在线Agent表现。同一运行只启动一个服务实例；需要换配置时先停掉该运行原服务。

试用前查看实际状态条，登记真实模型、mock或回放状态，保留出现的错误与项目方帮助。在线准备及温度实调已有独立记录，不等于待审实例已完成真人业务。

## 集中交给专业人员核对

1. 原生图与文字：A/B曲线各段速率、保温点、加料位置和红字时间口径；A组缺失单位继续保留未知。
2. 观察与边界：负例的型号后缀、同浴背景和同次合格对照；区分单次观察与通用判断。
3. 用途与授权：认可的候选原句、适用条件与温度范围、待补项、可对外说的原句和目标层级；不能确定时直接写尚不能确定。
4. 实际业务：专业人员完成系统确认与授予，产品经理按需批准，四岗位办理一次原单与下一单，记录帮助和反馈。

模拟链、在线准备、温度回归和来源副本复核均可从总入口回查。真人试用结束后再按实际记录更新V10.7/V10.10，不把开发者模拟数字填入真人成绩。旧实例及旧交接状态由Git和本地原运行保留为历史，本页不再指挥处理旧q编号。
