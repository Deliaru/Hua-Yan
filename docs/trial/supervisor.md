# 研发负责人试用说明

**入口**：选身份时点「研发负责人」下面你的名字，进入「研发负责人」工作面。你可以在业务处理之后再来查看，时间不限。

## 看进展

- **觉视图**：右上角选一张需求单，从客户提出需求到发布，觉每一次提出了什么、为什么提出、交给谁准备、谁签了字，都按时间列出。卡片右上角标「规则」的是模板规则打分，标「Jue-K」的是学习模型打分。
- **知识与积分**：谁的知识被引用、被复用，谁授予的能力被用了几次。

## 处理例外

工作面上出现的是觉提出、需要你决定的风险。目前只有一类：**某位业务员的检索集中在同一产品的研发知识上，要不要冻结他的上层知识检索。**

| 按钮 | 作用 |
|---|---|
| 冻结上层知识检索 | 冻结后，这位业务员和他的 Agent 只能看到说明书和用法，解密申请也会被挡下 |
| 现在不需要 | 你判断这是正常业务，不冻结。觉 24 小时内不会再提 |
| 解冻 | 在「已冻结」列表里恢复这位业务员的检索 |

**注意**：这项判断目前用规则打分，只按次数和集中度计数。业务员为客户正在用的产品反复问用法，也可能被提出来。请看证据里列的检索，判断是正常跟单还是在打听原理。试用里的人名和标「模拟」的内容都是模拟数据。
