# 研发负责人试用说明

V10首份报告当前状态和四岗位安排见 [四岗位交接](first-report-v10.md)，本轮实际查看与反馈按 [记录模板](v10-session-template.md) 填写。

**入口**：选身份时点「研发负责人」下面你的名字，进入「研发负责人」工作面。你可以在业务处理之后再来查看，时间不限。

## 看进展

- **觉视图**：右上角选一张需求单，从客户提出需求到发布，觉每一次提出了什么、为什么提出、交给谁准备、谁签了字，都按时间列出。卡片右上角标「规则」的是模板规则打分，标「Jue-K」的是学习模型打分。
- **知识与积分**：谁的知识被引用、被复用，谁授予的能力被用了几次。

## 处理例外

工作面上出现的是觉提出、需要你决定的事。原来有一类「某位业务员的检索集中在同一产品的研发知识上，要不要冻结他的上层知识检索」：它会把正常跟单（为客户在用的产品反复问用法）误报出来，**试用里不提出**。信息控制由分层访问、授予和撤销负责：业务员和他的 Agent 只看得到本层的内容，研发授予的能力可以随时撤销。

试用里的人名和标「模拟」的内容都是模拟数据。
