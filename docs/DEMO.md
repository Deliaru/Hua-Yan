# 演示脚本

> 人物、客户、产品、知识全部为模拟数据。台词与 `demo/mainline.yaml` 一致，按原句发送才能命中录制缓存；现场改了台词就是真实调用。
> 主线：一段需求从客户的场景语言，经 L1 → L2 → L3 逐层转成化学语言，再回流到 L1。由角色助手驱动，人只说话和点确认卡。

## 开场前

| 模式 | 启动 | 什么时候用 |
|---|---|---|
| 现场运行 | 设置好 `.env` 中的密钥，`HUAYAN_CONFIG=<现场配置> uv run python -m huayan.ui.server` | 网络与接口正常 |
| 记录回放 | `HUAYAN_CONFIG=config/app.replay.yaml uv run python -m huayan.ui.server`（A 提供） | 现场网络或接口出问题；顶部显示「记录回放」 |
| 离线演示 | `uv run python -m huayan.ui.server`，产品经理页点「载入离线主线」 | 兜底：不调用大模型，脚本代替起草与确认，状态条标注「确认由离线脚本代替」 |

浏览器打开 http://127.0.0.1:8766 。顶部依次是：业务员、产品经理、研发、三层对照、评测；右上角 ↻ 是「新开一轮」。命令行版（同一台词、同一结果）：`uv run python scripts/demo_mainline.py [--live]`，现场录制的完整轨迹见 `runs/demo_record/live_transcript.txt`。

## 不能说的话

- 不说「已接入传化数据」：人物、客户、产品、知识全部是模拟数据，种子为占位数据。
- 不说「零泄露」：分层隔离挡得住前台助手，挡不住从大量结论反推原理，后者靠泄露风险发现来缓解（业务周上觉原型的泄露风险结果受检索噪声影响、不成立；Jue-K 依赖当前检索口径，见 `docs/reports/week/README.md`）。
- 不说「真实业务已验证」：失真对照、业务周都是模拟客户和模拟业务周上的相对比较；G1 的转述噪声是假设参数。
- 不把演示里的概率数字说成实测结果。
