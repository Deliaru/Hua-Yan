# 业务流程演示讲稿

> 跟着页面顶上的「下一步」走，一个岗位接一个岗位讲。引号里是可以直接说的话，括号里是手上的动作。全程大约 10 分钟。

## 开场（30 秒）

「我们拿传化功能化学的一条真实业务线来演示：印染厂客户遇到问题，过去要经过业务员、产品经理、研发一层层转，常常一两天才有答复，还会在转述里丢条件。

今天屏幕上的客户由导演扮演，业务员、产品经理、研发这几个岗位由我来点。大家留意一件事：每一步都是化言把事推到人手上，人只做判断和签字。」

## 第一段：需求进来，化言接住每一位客户

**1. 常规问题，客户自助**（客户页）

「印染厂 A 一上来只说了一句：布染出来深一块浅一块，这个助剂能不能用？他没说面料，也没说设备。

化言没有直接给答案，而是像懂行的同事一样问回去：什么布？什么缸？多少度？问清以后，它按研发授权过的说明当场给出推荐。

这件事业务员、产品经理、研发都没被打扰。过去这种常规问题，也要一层层转，等上一两天。」

**2. 商务诉求，交给业务员**（切到业务员）

「印染厂 B 拿到推荐后说：我想要个报价。这就不是技术问题了，觉把会话转给了业务员。

（点化言消息里的「去处理」）大家看，业务员接手时，客户的原话和问清的条件都在，不用再问一遍，直接报价就行。」

**3. 过去没解决的客户**（研发）

「这位客户问的是涤纶、气流缸、133 度。说明书只写到 130 度，当时也没有试样，研发就没立项。

在过去，这件事就散在聊天记录里了。在化言里，它挂在一个对象上，后面我们会看到它被找回来。」

**4. 新问题直达研发**（研发 → 产品经理）

「印染厂 C 说布一洗就掉色。现有产品的适用范围里没有这个情形，于是事情直接到了研发手上。

研发看到的是客户原话和问清的条件，每条都能点回出处，不是转了两手的描述。研发判断现成的清洗剂 TF-288B 就能解决，选上产品、写清原因，客户马上收到推荐。

接着觉提醒产品经理：研发判断了一种说明书没写的用法，要不要扩进适用范围？产品经理签一下，再把说明书补上一句。以后同样的问题，客户自己就能查到。」

**5. 试样失败，当天回问补齐**（研发）

「这一单客户没说用的什么染料，第一次试样失败了。

研发在「录入不通过」里勾上缺的条件，也就是染料类别。化言直接去问客户，客户的回答回填到原单上，第二次试样就通过了。

过去这要研发、产品经理、业务员、客户一层层转回去问，常常问不准，要返工好几轮。」

**6. 产品机会**（产品经理）

「两家涤纶厂各自说白布不白，资料库里也没有对口的增白产品。觉把这两件事合在一起，问产品经理要不要立一个课题。

产品经理一次拍板。零散的短平快就汇成了一个中长期课题，研发也不会被琐事占满。」

## 第二段：老结论首次放行，组织记住

**7. 老结论首次放行到前线**（研发 → 产品经理）

「这一段用的是一份 2024 年的真实试样报告：汽流染色机，133 度保温，匀染良好。这个结论一直躺在研发电脑里。

化言把报告读出来，编成候选结论交给研发。（研发页）研发对着报告原文看一遍，确认 133 度这个条件，签字。产品经理再批准扩进适用范围。

从这一刻起，这份经验就不只在一个人脑子里了，组织记住了它，范围和条件也都写清了。」

**8. 同条件的下一单直接复用**（客户页）

「又来一位客户，同样是涤纶、气流缸、133 度。这次化言当场给出推荐，依据就是研发刚签的那条判断。研发零打扰，客户马上有答复。」

**9. 条件不符，照样回研发**（研发）

「再来一位，现象一样，但他是 135 度，超出了研发确认过的 133 度。

化言不会觉得「差不多」就推，而是把这件事交回研发，同时准备好方案包。研发看过以后接单，安排试样。我们的效率不是靠放松把关换来的。」

**10. 报告改版，复核**（研发）

「这时那份报告的来源改了一处。依赖它的能力立刻停下来，等研发复核。

研发看过改动：只是补记了一句风机速度，133 度的结论不变，保留。能力随即恢复。过去资料改了，没人知道引用它的结论要不要跟着变。」

## 第三段：判断回流

**11. 研发判断找回过去的客户**（业务员）

「还记得第 3 件那位 133 度的老客户吗？研发这次的判断一生效，觉就在历史里把他找了出来，提醒业务员去回访。

业务员发一句话过去，客户就拿到了推荐。没解决的客户不会被忘掉。」

**12. 说明书跟上研发判断**（产品经理）

「最后，研发确认的 133 度超出了说明书写明的 125 到 130 度。觉提出更新说明书，产品经理签一下，就同步到了公开层，下一位客户看说明书就知道。」

## 收尾（30 秒）

「回头看这一圈：客户说的话在一个地方被理解一次，之后一路带着原话和出处走。每一步都是化言把事推到对的人手上，人只做判断和签字。研发签过一次的判断，会变成下一单可以直接复用的组织能力，条件对不上就照样交回人。

这就是我们说的组织级 Agent Harness：让企业的经验真正被组织记住，并且用得放心。」
