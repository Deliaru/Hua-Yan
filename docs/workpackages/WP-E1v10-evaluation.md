3. 来源分组不能横跨dev/heldout；默认只检查dev，heldout预留不作调试或模型成绩。
4. 词表未覆盖项列出原词与理由，不扩词表或强制映射。
5. 一条命令完成合成离线检查，产出summary.json、report.md和逐条明细；无模型请求，无正式业务写入。
