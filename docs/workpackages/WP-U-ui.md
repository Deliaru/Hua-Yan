# WP-U 界面：业务员、产品经理、研发三个页面

> 负责：A｜时段：5:45–7:15｜分支：`dev/a`

## 目标
用 Streamlit 把演示主线做成可以现场操作的三视角工作台。界面只负责展示和输入，**所有权限裁剪都在门面里完成**。

## 依赖
WP-I。

## 必读
`CONTRACTS.md` 第 ⑫ 节；`workpackages/README.md` 首版 Demo 验收；`docs/VISION.md` 第 4 节（三层角色）。

## 允许修改的范围
`src/huayan/ui/app.py`、`src/huayan/ui/common.py`、`src/huayan/ui/pages/1_业务员.py`、`2_产品经理.py`、`3_研发.py`

## 交付物与已定设计

### 1. 公共部分 `ui/app.py`、`ui/common.py`
- `HuayanApp` 放在 `st.cache_resource`；侧边栏：身份下拉框（来自 `actors`，无登录）、「新开一轮」按钮（新 run）。
- **每页顶部状态条**（来自 `app.status()`）：`模拟数据`｜种子是否占位｜Jev 实现（mock / llm_fallback / onejev，降级时标黄）｜觉实时模型（规则原型 / Jue-K）｜抽取器｜转译引擎（规则 / 大模型，取 `gateway_mock`）｜现场运行或记录回放。
- `common.py` 增加**需求条目组件**：每条显示文本、可展开的客户原话（`quotes`）、依据标签「{归属人} · {知识标题或『L3 转化知识』} · 被引用 n 次」。三个页面和 WP-E 的三层对照页共用。
- `common.py` 只放显示小组件：槽位原话表、卡片、问题卡片（含证据与 `scored_by`）。

### 2. 业务员页（L1）
- 选择或新建会话（选客户）；对话记录；输入框 + 说话人切换（客户 / 业务员）；**「下一句」按钮**按 `demo/mainline.yaml` 填入台词，现场不用打字。
- 右侧：觉的追问提示（话术、概率），点「用这句追问」直接以业务员身份发出；槽位表（取值、原话、置信度）；推荐卡片（L1 版本）；L1 回复中被拦截的内容显示为「研发保密」。
- 满足条件时显示「为客户申请解密」。
- 当前身份不是 L1 时，提示切换身份，不显示输入框。

### 3. 产品经理页（L2）
- 问题队列：`escalate_need` 与 `opportunity`（标明「Jev 升级」或「觉发现」、概率、`scored_by`、证据）。
- 「起草产品需求」→ L2 条目（需求条目组件）；可编辑后确认，提示「已交研发转译」。
- 研发确认 L3 后，可查看化学语言需求单：所引 L3 知识只显示归属人，不显示原文（来自 `requirement_view`）。
- 「包装说明书」：输入为产品需求与研发的对外要点，生成说明书与用法，可编辑；「发布新品」后提示「L1 知识库已更新」。
- 积分榜（`ledger.totals()`）。

### 4. 研发页（L3）
- 待转译需求单：「起草化学语言」→ L3 条目（需求条目组件，所引知识原文可见）；每条可编辑，改完可点「**沉淀为我的转化知识**」（`contribute_translation`）；确认。
- 选择会话查看完整内容（卡片 `internal` 版本）。
- 试样录入表单；「对外要点」输入框（研发决定什么可以出 L3）；解密审批（只显示 `owner_id` 为当前身份的）；知识冲突问题（「更新说明书适用范围」按钮）。
- 「我的知识」：自己的转化知识被引用次数、被哪些需求单使用、积分明细（`contributions`）。

## 验收
按 `workpackages/README.md` 首版 Demo 验收第 1、3、4、6 条，在界面上从头操作一遍；录一段 3 分钟以内的屏幕录像或截图序列放进 `docs/assets/demo/`。
