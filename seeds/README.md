# 种子数据（占位）

全部为**模拟数据**：由大模型按印染行业常识编写，型号（`HY-` 开头）、客户、人物、配方要点均为虚构，不含任何企业资料。企业种子到位后整体替换，重跑 WP-B3。格式见 `docs/CONTRACTS.md` 第 ① 节。

| 文件 | 内容 |
|---|---|
| `slots.yaml` | 7 个槽位：fiber、dye_class、process、equipment、bath_ph、water、constraint |
| `phenomena.yaml` | 10 个现象，含必问槽位与 `slot_priors` |
| `products.yaml` | 15 个已发布产品 + 2 个研发中（`HY-LV206`、`HY-AS960`） |
| `cases.yaml` | 8 个历史案例，`case:7`、`case:8` 当时无合适产品 |
| `translations.yaml` | 50 条转化对照：L2 16 条（产品经理，场景说法 → 产品需求语言）、L3 34 条（研发 R01 13 条、R02 21 条，产品需求说法 → 化学语言），每条带 `phenomenon_ids` |
| `actors.yaml` | 2 业务员、4 客户、1 产品经理、2 研发（R01 染色过程化学，R02 弹力面料与整理）、1 主管 |

## 演示主线依赖的关系（均用 `huayan.domain.match_candidates` 验证）

| # | 关系 | 结果 |
|---|---|---|
| 1 | `color_unlevel` 只知道现象时候选 ≥ 2，`fiber` 与 `equipment` 都能改变候选集 | 候选 `HY-LV101`、`HY-LV120`、`HY-LV205`；fiber 分出 3 种候选集，equipment 分出 2 种 |
| 2 | 锦纶氨纶 + 溢流染色机 → 唯一候选 `HY-LV205` | 通过 |
| 3 | 锦纶氨纶 + 气流染色机 → 无候选（升级）；发布 `HY-LV206` 后命中 | 发布前 `[]`，发布后 `[HY-LV206]` |
| 3b | 转译链：升级对话命中 ≥ 2 条 L2、产品需求条目命中 ≥ 3 条 L3 且分属两位研发；`HY-LV206` 机理与 L3 译文一致 | 对话「深一块浅一块 / 锦纶氨纶，尼龙加弹力 / 气流缸」→ L2 命中 `tr:1` 深一块浅一块、`tr:2` 气流、`tr:3` 弹力；L3 命中 R01 的 `tr:17` 匀染、`tr:18` 低浴比、`tr:19` 上染均匀性，R02 的 `tr:21` 锦纶氨纶、`tr:22` 氨纶保护、`tr:23` 气流染色机、`tr:24` 弹力面料，产品经理补「不能影响色光」后再命中 R02 的 `tr:25` 色光。`HY-LV206` 机理 = R01 的缓释酸调 pH（`tr:18`）+ R02 的氨纶保护（`tr:22`） |
| 4 | 某必问槽位先验 > 80% 且该取值不改变候选集 | `shade_variation.water`：自来水 0.85，在 fiber 任意取值下都不改变候选集；只有软水、硬水、回用水才会分开 `HY-CH310` / `HY-RP330` |
| 5 | 留给「知识冲突」注入的产品与面料 | `HY-LV101` 的 `fiber: 涤棉`（说明书写适用，模拟业务周中注入涤棉试样连续失败） |

其他供核对的设计：

- **派单与归属**：`color_unlevel` 的 L3 转化对照 R02 6 条、R01 5 条，需求单确认后派给 R02（契约 ⑭「确认后派单」）；「低浴比」归 R01，产品经理助手检索时只看到「研发 R01 · L3」。`HY-LV206` 归属 R02（起草 L3、试样、发布记分），`HY-LV205` 归属 R01（主线第 6 步解密由 R01 审批，其机理含「弱酸性 pH 控制降低初期上染速率」）；
- **主线回问**：演示主题（锦纶氨纶 + 气流染色机）的需求单在 L3 起草时，只有染浴 pH 的 `trans_splits` = 2（`tr:50` 弱酸性浴），觉发起一次回问；L2 起草时不触发；
- **转译链完整**：每条 L2 的译文里都至少有一条同现象 L3 的 `scene_phrase` 作为子串，两步转译能连起来；

- `case:7`（锦氨 + 气流色花，无产品）与 `case:8`（锦氨分散沾色，无产品）分别对应研发中的 `HY-LV206`、`HY-AS960`；
- 必问清单里有「问了也不改变候选」的槽位：`harsh_hand.process`、`low_whiteness.process` 没有任何产品限定，`yellowing.constraint` 只在少见取值「低泡」时排除 `HY-AY901`；
- 按 `slot_priors` 抽样（无先验的槽位均匀），整体应升级比例约 **18.9%**：色花 12%、缸差 2.5%、色斑 7%、牢度 15%、手感 35%、折痕 25%、白度 15%、强力 28%、泛黄 7.5%、沾色 42%；
- 每条槽位口语说法、取值、现象说法单独出现时，`find_slot_values` / `find_phenomenon` 只识别出它自己；每个槽位的 `ask_text` 经 `detect_asked_slots` 只识别出自己。改说法时注意子串冲突（例如不要用「无」「酸性」这类会被其他说法包含的取值）。
